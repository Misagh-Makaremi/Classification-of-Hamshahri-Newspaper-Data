# Classification-of-Hamshahri-Newspaper-Data

In this project, we aim to identify a suitable model for classifying data from the *Hamshahri* newspaper using classification algorithms.
The attached dataset comprises 12,015 documents (news articles) from *Hamshahri* newspaper, organized into two columns.
The first column contains the news headlines, while the second column displays the text of each article.
The news items in this dataset have been pre-categorized into 12 news topics.
